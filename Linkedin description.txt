💡 About WorkforceHub:



WorkforceHub is a role-based HR management platform designed to streamline core workforce operations. The system supports three user roles — HR, Admin, and Employee — each with a dedicated portal and module set.



---



🔧 Key Features:



✅ AI-Powered Recruitment Pipeline — Resume parsing using Gemini 2.5 Flash, AI interview question generation using Groq/LLaMA, automated scoring and admit/reject recommendations



✅ Leave Management — Employee leave applications, HR approval workflow, automated attendance updates



✅ Payroll System — Attendance-based salary calculation with tax, provident fund, and loss-of-pay breakdown, payslip delivery via email



✅ Attendance Tracking — Daily login-based attendance, holiday management, leave duration tracking



✅ Employee Performance & Feedback — Star ratings, comments, AI-scored interview results



✅ Notifications & Activity Log — Real-time notifications, announcements, and audit trail across all roles



✅ Forgot Password Flow — OTP-based identity verification via email



---



🛠️ Tech Stack:



Frontend: React (Vite) — deployed on Vercel

Backend: Flask + SQLite — deployed on PythonAnywhere

AI: Google Gemini 2.5 Flash + Groq LLaMA 3.1

Email: SMTP via Gmail

Version Control: GitHub
